Agent 協作 + Git Worktree

版本綁定 herdr 0.9.3 · 對照 官方 CLI reference · 列印用

五個 agent 狀態

狀態意義備註
working執行中prompt 可送達
blocked認出 approval / question UI嚴格判定：只 match 已知 UI；prompt 送入會被拒（agent_blocked）
idle完成且已被看見read 不 mark seen、focus 才會；CLI 視角常是 done，TUI 點過去才變 idle
done完成但未被看見
unknown無法有信心分類不等於完成；wait 需明確 --until unknown

Agent 協作 loop

# 1. split pane（--current = 呼叫者 pane；記得 --no-focus）
split=$(herdr pane split --current --direction right --cwd "$PWD" --no-focus)
pane_id=$(printf '%s\n' "$split" | jq -r '.result.pane.pane_id')

# 2. 啟動並命名 agent（25 種 kind：opencode, claude, codex, cursor, amp…）
herdr agent start <name> --kind opencode --pane "$pane_id" [-- agent-args…]

# 3. 派工 + 等待（單一有序提交；blocked 拒收；5 秒 stall gate）
herdr agent prompt <target> "工作描述" --wait --timeout 120000

# 4. 讀回覆
herdr agent read <target> --source recent-unwrapped --lines 120
指令用途
herdr agent list所有 live agents（JSON：名稱、狀態、pane、cwd）
herdr agent get <target>單一 agent 現況
herdr agent wait <t> --until <s> [--timeout ms]等到狀態；--until 可重複；預設 idle/done/blocked
herdr agent send-keys <t> esc|enter|ctrl+c低階互動（回答 blocked UI）；寫入前先驗證全部 key
herdr agent rename <pane-id> <name>手動啟動的 agent 事後命名
herdr agent focus <target>focus 過去（會 mark completion as seen）
herdr agent explain <target>除錯偵測判定：manifest 版本、matched rule、fallback 原因

TARGET = 唯一 live agent 名稱（[a-z][a-z0-9_-]{0,31}）或承載 pane ID（如 wK:p2）。不接受 terminal ID / agent kind。

Git Worktree（原生功能）

worktree = 帶 Git checkout 來源的 workspace：可 focus/rename/close、開 tabs/panes、跑 agents，與 parent repo workspace 自動分組。

# 建立（branch 已存在則 checkout；不存在則從 --base/HEAD 建立）
herdr worktree create --cwd ~/Projects/my-repo --branch review-api --label review-api --no-focus

# 開啟既有 worktree（--path 或 --branch 擇一）
herdr worktree open --cwd ~/Projects/my-repo --branch review-api

# 列出 / 移除（remove 跑 git worktree remove，不刪 branch；dirty 才需 --force）
herdr worktree list
herdr worktree remove --workspace <id> [--force]
項目說明
預設目錄[worktrees] directory = "~/.herdr/worktrees"，checkout 在 <directory>/<repo>/<branch-slug>
--trust-repository每次請求授予 Git trust；不是失敗重試的常規選項
close vs removeworkspace close 只關 herdr state（checkout/branch 都留）；worktree remove 才刪 checkout
groupworkspace close --group 關閉 primary + 連動 worktree workspaces——要小心

每 agent 一 worktree：create 之後在該 workspace 的 root pane 跑 agent start（create 與 start 是兩個明確步驟）。

安全守則（摘自內建 skill）

  • 背景工作一律 --no-focus；ID 從 JSON 解析，不用 sidebar 順序猜。
  • 用 --current、明確 pane ID 或唯一 agent 名稱；不要依賴別的 client 的 focus。
  • 不是自己開的 workspace/tab/pane/session 不要關。
  • herdr server stop 會停止 server 與全部 pane processes——除非明確要，永遠不要跑。
  • CLI server 錯誤：JSON on stderr、exit 1；語法錯誤 exit 2。
